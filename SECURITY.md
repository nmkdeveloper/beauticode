# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in BeautiCode, please do NOT file a public issue.

Instead, please send an email to:
**nguyenminhkhoi.nmk.dev@gmail.com**

Please provide:
- A description of the vulnerability.
- Steps or a proof-of-concept to reproduce the issue.
- Potential impact.

We will acknowledge receipt within 48 hours and work to issue a fix promptly.
